# Day 19 — Research Methodology & Data Analysis

## Project
**E-commerce Customer Purchase Behavior and Satisfaction Analysis**

Research question: *Does customer satisfaction significantly influence repeat-purchase intention in e-commerce?*

This educational project uses a **synthetic practice dataset**. It demonstrates research framing, data collection planning, questionnaire design, descriptive statistics, hypothesis testing, effect size, interpretation, and documentation. Do not present synthetic results as real customer evidence.

## Learning objectives
- Turn a problem into a research question and testable hypotheses.
- Distinguish primary and secondary data and define a sampling plan.
- Design a short, ethical survey.
- Summarize data and test a hypothesis.
- Interpret statistical significance and effect size together.
- Document methods, results, limitations, and reproducibility.

## Dataset
`data/ecommerce_satisfaction_sample.csv` has 120 fictional records. Each row is a synthetic respondent. Variables include satisfaction, repeat-purchase intention, age band, purchase frequency, and delivery rating.

## Analysis
The script validates the data, generates descriptive statistics and frequency tables, calculates Pearson correlation, compares repeat-purchase intention between lower- and higher-satisfaction groups using Welch's independent-samples t-test, and calculates Cohen's d. Results are saved in `outputs/`.

Hypotheses:
- **H0:** Mean repeat-purchase intention is equal for lower- and higher-satisfaction groups.
- **H1:** The means differ.
- Alpha = 0.05, two-sided.

For this practice, satisfaction <= 3 is classified as lower and >= 4 as higher. The cutoff is only a demonstration; predefine and justify any grouping in a real study.
